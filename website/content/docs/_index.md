description: "How to use TriTrack in the field."
---

New to TriTrack? Start with the [quick start](quick-start/): six steps from a
new install to the first bearing. Then read, in order, joining a project,
recording a bearing, and sync.

On a Mac, TriTrack is the same app with the same screens, except that a Mac has
no compass or GPS, so a bearing is typed with {{< app "Manual entry" >}}.

Every picture is generated from the app over invented data; no tag, person or
study area in them is real. The guide is written from an iPhone and does not yet
cover Android, or the shape of the viewshed boundary on the map, which is still
changing.
